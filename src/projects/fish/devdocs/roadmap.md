## 已实现基线

- 完整流程：主菜单 → 村庄基地 → 兵营训练 → 地图选关 → 战斗 → 结算
- 基地：6 种建筑网格建造/移动/删除
- 战斗：放兵、兵 AI 组件、A* 寻路、防御塔反击、按伤害比例实时掠夺、胜负判定
- 基础设施：存档、GM 控制台、调试桥

## 模块依赖关系

- 兵种升级 ← 建筑升级（实验室复用升级/计时体系）
- 关卡解锁 ← 星级评价（以星为解锁条件）
- 宝石 ← 成就/障碍物/三星奖励（产出渠道）；建造与研究 ← 宝石（加速消费场景）
- 英雄/法术 ← 战斗时限与星级（结算规则稳定后再叠加新单位）
- 新手引导 ← P0 经营闭环（引导教的流程必须已存在）

## 执行约定

- 每批完成后再开下一批；批内 P0 项可并行。
- 实现任何模块前先读对应模块文档的「边界条件」；实现后回写文档状态并补实际流程。

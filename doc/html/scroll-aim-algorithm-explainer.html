一、对中停止点怎么算

stopPoint = P − v̂ × floor
P = 天体球心  v̂ = 当前视线方向（单位向量）
floor = max(24, 半径×1.15) = 停止半径
把公式拆开看：点 − 向量 = 点
P = 天体球心 —— 是一个点（三维坐标）
v̂ = 单位视线方向（cam.getWorldDirection，从相机指向前方）—— 是方向
floor = max(24, r×1.15) —— 是标量距离
v̂ × floor = 方向乘距离 = 一个位移向量（长度恰好为 floor、指向视线前方）
P − 位移向量 = 从球心出发，朝视线的反方向（也就是朝相机这一侧）走 floor 那么长，落下来的那个坐标 —— 这就是 S
S 就是过球心、平行于视线的直线 ∩ 停止半径球面的相机侧交点（另一交点在天体背后）。锚点是球心——不是从相机打向目标的视线连线（相机歪着时两者是平行线，见下一页红圈对比）。相机到达 S 时： P − C = P − (P − v̂·floor) = v̂ · floor 球心到相机的连线恰好等于视线方向 → 球心投在视线轴上 → 屏幕正中心。视线冻结期间 S 是静止点 → 每滚一次都朝同一点直线收敛，越滚越近、也越滚越居中。

二、歪着时 S 怎么算 —— 先懂几何，再套公式

第一步 · 几何原理（先懂"为什么"）
① 相机只有两样东西：站位（人在哪）和朝向（脸朝哪）。滚轮只挪站位，朝向焊死不动。
② "对中" = 球心出现在画面正中心 —— 画面中心就是沿脸方向的那条直线（视线轴）。
③ 倒着想：人站在哪，球心才正好在脸的正前方？—— 从球心出发、朝脸的反方向退 74：站到那里，球心就在正前方 74 处，天然居中。
④ 左图两条平行线：过相机的视线 ∥ 过球心的线（S 在这上面）。相机只需走过去，不用转头，球心自己滑进画面中心。
第二步 · 公式计算（把几何翻译成坐标）：
① 读方向：v̂ = (0.454, −0.891)（−63°，只看脸朝哪）
② 位移 = v̂ × 74 = (33.6, −65.9)（朝脸反方向退 74）
③ S = (500,120) − 位移 = (466.4, 185.9)
附注：24° = |−39.0°−(−63°)|，P 处楔形与 C 处偏角是内错角（平行线被截线 CP 所截）。红点方向含站位（移动靶）、黄点 S 方向只含姿态（恒定不动）—— 所以公式只认球心和朝向，不认相机站位。

三、逐滚收敛 · 交互模拟

相机看到的（朝向冻结的取景框）
每点一次 = 滚一格：step = min(rig.step, 到停止点剩余距离)，offAxis（目标偏离视线轴的角度）一路收敛到 0。红圈 = 相机→球心连线 ∩ 停止球面：每滚一步就沿圆滑动（移动靶），飞到它目标仍偏着不居中；黄点 S 锚定球心（P − v̂×floor）恒定不动，才是算法的停止点。琥珀虚线是逼近路径 C→S，不是视线。

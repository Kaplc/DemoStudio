# 聚能环槽位化方案 V1（25 级 = 25 槽位）

> **一句话定位**：聚能环从「12 交点 + 25 级推导阶梯」改为「25 个环段槽位」——每建成一级交付一个空槽位，玩家花 H3 自选一座环上建筑装入；等级 = 已建成槽位数，环上建筑 = 玩家亲手搭出来的经济引擎。
> **什么时候会用到你**：实施本次改版时；调环上建筑数值/加新建筑时；排查等级、焚烧、船帽、研究点相关回归时。
> **状态**：设计定稿（2026-09-11 与用户对齐四项决策，同日追加拍板：拆除需花费时间），**未实施**。
> **设计理念**：玩家参与游戏的每一个环节，每一环都是自己设计的成果。

---

## 1. 核心改动

| 维度 | 改版前 | 改版后 |
|---|---|---|
| 物理单位 | 12 个交点（`s.nodes`） | 25 个环段槽位（`s.ringSlots`） |
| 25 级 | 由交点覆盖度**推导**（`ringLevelOf` 连续爬升） | = 已建成槽位数（同一推导式换标尺，仍随当前格进度连续爬升） |
| 升级时刻 | 纯数值跳变 | 交付一个**空槽位**，玩家花 H3 装入自选建筑 |
| 建筑体系 | 地图建筑（中转站/护盾）+ 轨道建筑（船坞） | 新增第三家族：**环上建筑**（全局经济修正，6 型起步） |
| 经济构筑 | 卡片单通道 | 卡片 + 环构筑双通道，焚烧曲线可被玩家削减 |

保留不变：建设流（点数控速、灌入即计费、`level_cost` 表）、堆心温度断环机制、`level_burn` 2^l 曲线基线、`ship_cap` 表、每级 1 研究点、焚烧/研究/建设三口消耗结构。

## 2. 玩家循环

```
灌 H3 建当前槽位 → 灌满交付（毛坯空槽）→ 玩家花 H3 自选建筑装入
→ 等级 +1（焚烧跳涨、船帽/研究点 +1）→ 环建筑修正经济 → 下一格
```

**核心张力：空槽也焚烧。** 等级随建成槽位走，`level_burn` 照样跳涨——不装建筑等于白白多烧。安装是让升级「值回票价」的手段，拆除重装是中期修正构筑的手段；安装点击即扣，拆除则**既花 H3 又花时间**（用户拍板：装、拆都要花钱，拆还要花时间）。

## 3. 环上建筑库（`ring_building.table.json`，6 型起步）

行键 = 建筑 id（`SimRingBuilding.type`），全部**全局效果、线性加算堆叠、无上限**（用户拍板完全自由堆叠，单座效果压低）：

| id | 名称 | 造价 H3 | 每座效果（线性叠加） | 实现挂点 |
|---|---|---|---|---|
| `regulator` | 稳压环段 | 200 | 全局焚烧 −4% | `SimStateComponent.burnRate` 乘 `ringBurnMult` |
| `conduit` | 超导馈线 | 260 | 全船满载 +3% | `helpers.starLoad` 乘 `ringLoadMult` |
| `berth` | 扩容泊位 | 400 | 船队上限 +1 | `shipCap` getter 加算（可与 ship_cap 表共存） |
| `constr` | 施工分段 | 300 | 建设灌入速率 +5% | `ringBuildCost` / `RingBuildComponent.tickBuild` 泵速乘区 |
| `feeder` | 研究馈能 | 240 | 全线研究速率 +4% | `helpers.researchRateOf` 乘区 |
| `heatwell` | 蓄热井 | 220 | 断环降温时长 +12%、回温提速 −8% | `B.coreCoolSeconds` / `B.coreWarmSeconds` 乘区 |

**防爆地板**（`ring_build.config.json` 可配）：加算总和封底——焚烧乘区不低于基线 20%，其余乘区不低于 0.5。阻止「25 格全稳压 → 焚烧归零」的死平解，同时保住极端构筑的爽感（25 格全稳压 = 焚烧降至 20%）。

**后期扩充位**（表加行即生效，无需改代码）：造船环坞（造船费/时长）、维护优化（舰队维护费）、耀斑雷达（预警强化）。

## 4. 规则细则

- **安装**：只能装入「已建成且空置」的槽位；安装费 = 建筑造价，点击即扣。
- **拆除**：已装槽位可拆，拆除**既花 H3 又花时间**（2026-09-11 追加拍板）。拆除费 = `造价 × demolishCostPct`（默认 20%），不返还（与地图建筑 `refundPct` 返还制**有意区分**：环段是焊死的基建设施）；拆除时长**复用建设流**——发起拆除后建设泵切到目标格「反向灌入」（同一点数控速、灌入即计费），拆除总耗时 ≈ 同格建设时长的 20%（拆除费 ÷ 当前泵速）。拆除期间：目标格建筑效果**立即停摆**（六型效果全为增益，停摆只亏不赚、无拆机套利）；同一时刻泵只灌一个目标，点当前格灌建设、点目标格续拆可来回切换，双侧进度各自保留并入存档；拆除进度**不参与等级推导**（等级仍按已建成槽位 + 当前格建设进度走）。拆完槽位回到空置，可再装。
- **拆装不降级**：拆除只摘建筑，已建成槽位数与等级不受影响。
- **断环**：堆心温度机制不变；断环时焚烧本就归零、研究速率本就归零，环建筑全局效果自然停摆，**不损毁**，回温自动恢复。
- **满级**：25 格全建成后建设流停灌（与现状满网一致），玩家继续做的是拆装重构。

## 5. 数值骨架

- **开局**：`startSlots = 1`，第 1 格已建成但**空置**——第一分钟引导玩家完成第一次安装（教学即机制）。
- **建设造价**：`level_cost` 表扩为 n1..n25，默认 **51/格 平价**（≈ 107 × 12 ÷ 25，总建设时长与改版前持平；交付时刻从 12 次翻倍到 25 次，决策密度翻倍）。可逐级改曲线。
- **等级推导**：`ringLevelOf(builtSlots, currentProgress)`，`raw = (built−1+progress) / 24`、`level = 1 + floor(raw × 24)`——保留现有「格子灌到一半等级条也在走」的手感，消费方（焚烧/船帽/研究点）口径零改动。
- **三幕门槛**：`act2Slots = 8`、`act3Slots = 16`（原 4/12、8/12 等比映射）。
- **研究点**：每级 1 点不变（25 级 = 25 点，总量与现状一致）。
- **平衡提醒**：环建筑安装是**新增 H3 池**（满配 25 座 ≈ 6000+ 吨），叠加焚烧 2^l 基线，中期经济会比现在紧——这是「构筑即经济」的题中之义，首版数值需实测回调。

## 6. 存档迁移 v8 → v9

- `nodes` → `ringSlots`：`round((n−1) × 24/11) + 1`（1→1、12→25 等比映射）；`ringBuildProgress` 原样保留。
- 新增 `ringBuildings: (string|null)[25]`，迁移初始全空（老存档不送建筑，玩家重新构筑）。
- 新增 `ringDemolish: { slot: number; progress: number } | null`（拆除中目标格与进度，泵切走时保留），迁移补 null。
- `SimMods` 新增环乘区字段（`ringBurnMult` 等），迁移补默认值 1。
- **v9 由两案合并承载**：本方案 + [玩家设计权扩展方案](./玩家设计权扩展方案-V1.md)（船型模块 `ships[].hull/modules`、建筑强化 `buildings[].upgrade`）同批迁移，见扩展方案 §四。

## 7. UI 与表现

- **RingPanel 改造**：详情面板加 25 段环形槽位图——已建成亮、未建成暗、当前格进度弧、已装格显示建筑图标；点空格弹安装列表（标价），点已装格弹详情（拆除按钮 + 拆除费与预计耗时）；拆除中目标格叠加拆除进度弧（视觉同当前格进度弧）。
- **升级瞬间**：hint「第 N 环段交付，可安装建筑」+ 面板对应格闪烁。
- **星图渲染**（`StarMapRenderComponent`）：地球聚能环改为 25 段弧，逐段点亮，已装格叠加小型建筑标记。
- **HUD**：详情面板当前格进度条照旧（消费 `ringBuildProgress` 不变）。

# 模块 09 · 胜负与结算

## 1. 概述
两条终局线：失败 = 聚能环停转（种族终结）；胜利 = 全球环网建成（文明新纪元）。

## 2. 失败条件（唯一硬性线）

- **判定（堆心温度式，2026-09-08 改版）**：`地球 H3 储量 ≤ 0` → 聚能环**断环**（停烧停建）→ 堆心**持续降温**（`coreCoolSeconds` 秒从满温降到 0）→ 温度归零 = 堆心熄灭 → 失败。期间补入燃料，环即恢复运转、堆心缓慢回温（`coreWarmSeconds` 秒回满），不会瞬间救回。旧「缓冲衰减倒计时 + 延续度」已下线（见模块 04）。
- **演出**：
  - 堆心温度进度条降至 0，转冷红。
  - 星图飞船光点熄灭，地球陷入死寂。
  - 弹出「人类种族终结 · 第 N 幕」结算面板（显示存活时长、累计卸货量等）。
- **重开**：提供"重试本幕 / 从头开始"。

## 3. 胜利条件

- **前置**：进入第三幕，获得"火星环扩展模块"运输任务。
- **达成**：将超重"环扩展模块"从火星运回地球，点亮全球 **12 个关键经纬交点**，聚能环扩展为全球环网。
- **演出**（"全球回暖"动画）：
  - 全球 12 个经纬交点微光连成覆盖整颗星球的光环。
  - 地球"存续之火"扩散为全屏暖光，堆心温度定格（平稳度过微休眠期）。
  - 字幕：人类文明平稳度过微休眠期，进入新纪元。

## 4. 结算面板字段（建议）

| 字段 | 说明 |
|------|------|
| 结局 | 终结 / 新纪元 |
| 存活时长 | 本局总秒数 |
| 抵达幕次 | 1/2/3 |
| 累计卸货 H3 | 总补给量 |
| 建造补给站数 | 基础设施投入 |
| 已解锁科技节点 | 最终已解锁节点数（= 覆盖段） |

## 6. 待确认 / 开放问题
- **（已定）** 失败采用堆心降温（临终喘息，2026-09-08 改版替代原方案 B 缓冲）；胜利后进入沙盒延续模式（无失败压力）；结算不做 S/A/B 评级，仅给出局/胜利与统计。

# 模块 10 · UI 与美术方向

## 1. 概述
底部横条式布局，适配电脑/手机。配色强调"死寂宇宙 vs 存续之火"的对抗。所有数值来自模块 01~04。

## 2. 配色规范

| 角色 | 色值（建议） | 用途 |
|------|--------------|------|
| 冰蓝（主背景） | `#0E2A3A` 系 | 深空、死寂 |
| 暗灰（面板） | `#1A1F26` | 底部横条、卡片 |
| 炽热橙红（高亮） | `#FF6A3D` / `#FFB03D` | 飞船、燃料数值、延续度、关键按钮 |
| 告警冷白 | `#BFE9FF` | 储量危险时指标闪烁 |

> 对抗逻辑：冰冷背景中，一切"与人类存续相关"的元素用橙红点亮。

## 3. 三区布局

### 顶部（主指标区）
- **人类种族延续度**：横向主条，带血条变色（满=橙红，危险=冷白闪）。
- **当前总需求数字**：聚能环实时消耗率（吨/秒）+ 地球储量余量。
- **引力窗口倒计时**（二幕后）：小计时器。

### 中间（星图区）
- 资源星节点（月球/木卫二/火星）+ 地球节点。
- 航线：点线连接，飞船以橙红光点沿線移动。
- 交互：拖拽画线建航线；点击航线选中/删除。
- 事件层：耀斑时全图泛白噪点；引力窗口时木卫二线高亮。

### 底部（操作横条）
- 飞船列表（在途/空闲）。
- 燃料存量（地球 H3 储量数字 + 迷你条）。
- **研究线总览 + 超频按钮**（模块 03/05，纯多线系统，无常驻升级按钮；点选研究线开启 H3/秒 超频）。

## 4. 素材关键词（商用付费站）

- `Sci-fi HUD kit`
- `Frost UI pack`

## 5. 反馈与演出（治愈核心）
- 卸货瞬间：地球节点脉冲橙光 + 储量数字跳动 + 延续度轻微"回升"动画。
- 进化事件：环等级数字跃升 + 全屏短暂暖光扫过。
- 失败/胜利：见模块 09 演出。

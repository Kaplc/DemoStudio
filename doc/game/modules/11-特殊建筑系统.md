# 模块 11 · 特殊建筑系统

## 1. 概述
玩家可在星图上放置"**特殊建筑**"——区别于自动生长的聚能环，它们是玩家主动布置的基础设施。每座建筑可**单独升级等级**（1→N，**设计意图，当前未实现：建筑无等级字段/升级 API**），等级越高，其专属属性越强。当前实装：**中转站**（可被航线链接、缓存建材）与**磁场护盾发生器**（原"无人补给站"，抵御极寒停航，见模块 07），另有近地轨道**船坞**（轨道建设面板）；后续可扩展其他类型。

**与模块 03 的「解锁 / 升级」二分对齐**：建造权限来自基建线的「解锁」型节点（如"补给站解锁"= 开启新功能）；而点击建筑本身升等级 = 「升级」型（加强属性）。解锁给"可能性"，升级给"更强"，两者不同层。**（设计意图，当前未实现：卡库无"补给站解锁"卡，建筑在建造面板直接可建；建筑升级 API 亦未实装。）**

## 2. 特殊建筑列表（候选）

| 建筑 | 作用 | 随等级提升的属性 |
|------|------|------------------|
| 无人补给站 | 极寒停航时保护在途船不冻毁 | 保护半径、可保护船数、事件后恢复速度 |
| 中继导航塔（候选） | 提升某航线段速度 / 延长引力窗口 | 提速幅度、覆盖段数 |
| 燃料缓存库（候选） | 中途缓存 H3，降低往返油耗 | 缓存容量、减耗比例 |

> 当前实装：**中转站**、**磁场护盾发生器**（`building.table.json`）+ **船坞**（`orbit_build.table.json`，近地轨道）。中继导航塔 / 燃料缓存库为候选，是否加入待定（避免早期复杂度过高）。

## 3. 放置与单独升级

- **放置**：在航线中点 / 星图节点拖放（交互近似"画线"）。
- **入轨（2026-09-08 拍板）**：放置点距某行星中心 ≤ `B.build.orbitAttach`（400px）时，建筑自动**锚定该行星入轨**——形成一条绕行星的本征轨道（半径 = 放置距离，按「行星显示半径 + orbitMinPad」抬底；切向速度 `B.build.orbitSpeed` 1.5px/s，离行星越近角速度越快），随行星一起绕日公转。远离行星放置 = 静态建筑（行为同旧版）。实时位置由 `buildingPos`（纯时间函数）统一给出：渲染、点击拾取、航线端点、反向补给线距离、耀斑护盾判定全部跟随实时位——护盾不再与行星"渐行渐远"。太阳不作锚（静态无公转意义），卫星可作锚（月球旁放置绕月公转）。旧档建筑无锚定字段 = 静态，读档无需迁移（存档 v8）。
- **单独升级**：点击某座建筑 → 升 1 级；每座独立计算等级，互不影响。**（设计意图，当前未实现：无升级入口/API。）**
- **成本（已定：H3）**：建站消耗 H3（表内 `cost`），与模块 03「加速研究」同源，强化"H3 即一切"的核心张力；每级升级的额外 H3 为设计意图、当前未实现。*（注：不再引入第 3 种货物——反向航线的"建材"也从 H3 折算，见模块 01/02。）*

## 4. 补给站等级表（示例初值 · 设计意图，当前未实现）

> 现版本建筑无等级：磁场护盾发生器为表内固定值（半径 220px、耀斑保全 2 船、恢复延迟 3s，`building.table.json`），**无升级 API**；下表为规划中的等级化设计。

| 等级 | 保护半径 | 可保护船数 | 事件后恢复 |
|------|----------|------------|------------|
| Lv1 | 近 | 2 | 慢 |
| Lv2 | 中 | 4 | 中 |
| Lv3 | 远 | 8 | 快 |

> 等级越高，极寒停航时能保住更多在途船，间接保护运力与补给链不断。

## 5. 与其他模块的交互
- → 模块 07：补给站（磁场护盾发生器）是抗极寒停航前提；升级强化为设计意图、当前未实现（本模块为其属性规划载体）。
- → 模块 03：升级成本与「加速研究」同源（都吃 H3），构成资源权衡。
- → 模块 02：建筑保护航线上的在途船，影响运输稳定性。
- → 模块 01：建筑成本出自地球储量 / 运力。

## 6. 待确认 / 开放问题
- **（已定）** 建筑升级成本统一 **H3**（不引入第 3 货物，**升级体系为设计意图、当前未实现**）；补给站保护范围为**磁场护盾范围**（实装为背日罩）；**多个护盾范围重叠时取并集**（覆盖区域合并变大，鼓励沿航线重叠布站）；每类建筑**等级上限 Lv3**（设计意图，当前未实现）；允许**拆除返还 50% H3**（不可降级）；单图建筑数量**不硬上限**（受 H3 约束）；**首版实装：中转站、磁场护盾发生器、船坞（近地轨道）**，中继导航塔 / 燃料缓存库为后续候选（待定，避免早期复杂度过高）。
- 护盾半径 / 可保护船数 / 重建 H3 成本等数值待平衡。

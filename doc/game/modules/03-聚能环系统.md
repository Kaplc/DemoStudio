# 模块 03 · 聚能环系统（含科技 / 研究）

## 1. 概述
"环赤道聚能环"是文明的具象化身。它内置**多条第技研线**，各线随存续进度**并行自动推进**；玩家可投入**额外 H3** 加速某条线。每当某条线抵达一个"节点"，触发**海克斯式三选一**，选定即**解锁该科技节点**（永久效果：或是开启新功能，或是加强已有属性），同时环点亮一个**新的全球经纬交点**（覆盖+消耗）。12 个交点全亮 = 全球环网 = 胜利。

## 2. 多线并行研究

- 环同时跑多条研究线，每条线独立进度、独立节点序列。
- 示例线（初版）：

| 线 | 系 | 示例节点效果 |
|----|----|--------------|
| 引擎线 | 产能 | 油耗 −15% / 速度 + / 月球富集 |
| 货舱线 | 产能 | 货舱 +20% / 扩编船 |
| 基建线 | 基建 | 补给站解锁 / 引力延长 / 事件预警 |
| 扩张线 | 扩张 | 生长加速 / 双生节点 |

- **环线已移除（2026-09-08 拍板）**：聚能环物理建设/计费已独立成建设流（`RingBuildComponent` + 聚能环详情面板，存档 v6），原环线卡（环节能/储备扩容/恒温冗余）下线，科研固定四线。

- **推进方式（2026-09-08 改版：纯点数驱动）**：原"按真实时间被动推进"已废弃；现在研究**无点数速率为 0**，进度全靠科研面板分配的研究点推进（每点 = 基础速率 × (1 + 0.5×点数) 加算提速，同时按点持续计费 H3）。环运转加成保留（断环/储量耗尽时点数加成失效速率为 0）。
- **节点暂停（2026-09-08 拍板改版：弹卡即暂停）**：某线进度满一个节点 → **游戏整体暂停**，弹出海克斯三选一（见 4）。**暂停语义（2026-09-08 改版）**：选卡前仿真**整体冻结**（时间不走、飞船/经济/事件全部静止），不再是"仅冻结研究、其余照常"的旧语义。旧"15 秒自动收纳 + HUD 徽标重开"机制**已下线**（hexHiddenAt/hexAutoCloseSeconds 字段删除，存档格式 v4 兼容清理），选卡是唯一出口。

## 3. 加速研究（消耗额外 H3）

- 玩家可主动花 H3 推进指定线，让它更快抵达下一个节点。
- **形式（已定：持续超频）**：玩家选定一条研究线并开启超频，持续花费 `H3/秒` 让该线提速 `Y%`，直到再次点击关闭。**可多条线同时超频（已定）**：每条线独立计费、成本随超频线数累加（给力但贵）；缓冲衰减 / 储量 ≤ 0 期间超频自动不可用（无处可烧）。
- **张力**：超频 = 该线更快抵达下一节点 = 环更早生长/更接近胜利，但持续消耗 H3、且新节点带来的消耗也更早到来（与生存直接争夺燃料）。

## 4. 节点解锁 = 海克斯三选一

- 某线进度满一个节点 → 暂停 → 从 3 张随机方向卡三选一（海克斯式）。
- 选定即解锁该节点：施加永久效果 + 环物理延伸一段（覆盖+）。
- **两类效果（核心规则）**：
  - **科技解锁（获得新功能）**：开启原本没有的机制 / 可建造物 / 系统。一次性，给你"可能性"。
  - **普通升级（加强属性）**：在已有功能上提升数值。可多级叠加，给你"更强"。
  - 例：基建线"补给站解锁"= 解锁（从此能建补给站）；而补给站本身升到 Lv3 = 升级（模块 11）。二者不同层，不要混。
- 候选池（每局可洗牌）按「类型」分列如下：

| 卡 | 类型 | 所属线 | 效果（永久） | 代价（tradeoff） |
|----|------|--------|--------------|------------------|
| 补给站解锁 | **解锁** | 基建 | 开启"无人补给站"建造权限（模块 11） | 单节点消耗 +3% |
| 事件预警 | **解锁** | 基建 | 极寒停航提前 10 秒预告 | 该线下次生长 −10% |
| 引力窗口开启 | **解锁** | 基建 | 开启"引力弹弓窗口"机制（模块 06，若二幕前未自带） | 环节能 −5% |
| 引擎超频 | 升级 | 引擎 | 所有航线油耗 −15% | 航速 −5% |
| 航速提升 | 升级 | 引擎 | 飞行速度 +20% | 油耗 +8% |
| 月球富集 | 升级 | 引擎 | 月球单船满载 +50 | 其他星满载 −10 |
| 扩容货舱 | 升级 | 货舱 | 单船货舱 +20% | 单船油耗 +10% |
| 扩编船队 | 升级 | 货舱 | 飞船 +1 | 单节点消耗 +5% |
| 引力延长 | 升级 | 基建 | 引力窗口 +5 秒 | 单节点消耗 +2% |
| 生长加速 | 升级 | 扩张 | 下一节点进度条提速 | 单节点消耗 +6% |
| 环网扩容 | 升级 | 扩张 | 聚能环建设计费 −25% | 该线下次生长 −20% |

> **（2026-09-08 环线卡下线）** 原「环节能 / 储备扩容 / 恒温冗余」三张环线卡已随「延续度 + 缓冲倒计时」模型一并删除（科研固定四线：引擎/货舱/基建/扩张）。「储备扩容（+缓冲秒）」「恒温冗余（+延续度回升）」的机制载体已不存在，见模块 04 堆心温度改版。

> **（已定）卡带 tradeoff · 策划预设**：采用**固定得失组合**（上表每卡"得"与"代价"一一预设，不再随机配对），平衡可控、易学习；逼玩家在"得"与"失"间权衡。
> **（已定）候选池每局随机洗牌**：每局从完整卡库随机抽选可用卡，重玩性高。
> **（已定）抽卡范围**：海克斯三选一默认从**触发节点所属线**的卡池抽 3 张（同类最相关、更策略）；若该线候选不足 3 张，则从全局候选池补足。
> 设计要点：解锁型卡多出自**基建线**（给新玩法），升级型卡散布各线（堆数值）；每张均带 tradeoff。

## 5. 节点生长与覆盖（物理层）

- 全球分 12 个关键经纬交点；**每解锁 1 个科技节点 = 环覆盖 1 个交点**（1:1 绑定，已定），不再是单纯赤道带状。
- **交点解锁单流 · 造价制（2026-09-08 拍板）**：**聚能环建设流是交点唯一来源**——底部 HUD「聚能环」入口打开详情面板，用建设点数控制灌入速度：每点每秒把 `costPerS`（`ring_build.config.json`，默认 2）吨 H3 从地球储量实扣灌入当前交点，**建设进度 = 本级已投入 ÷ 本级造价**（`level_cost.table.json` 逐级定价，默认全级 107 ≈ 旧速率制隐式造价），灌满 → 交点点亮 +1；点数 0 停灌（0 计费），储量耗尽（断环）停灌停费。卡效果 `ringBuildCostMult` 在造价制下折扣本级造价（省总 H3 = 同速更快）。研究线选卡不再 +1 交点（原保底解锁已移除，选卡只出效果），火星模块交付只判胜利、不再点亮剩余交点；twin_node 的 extraNodes 批量交点效果已废弃（卡位保留为造价折扣增益）。
- 阶段（按已覆盖交点数）：Lv1(1,~8%) / Lv2(~4,~33%) / Lv3(~8,~67%) / 终局(12,100%→全球环网=胜利)。
- 每节点 +覆盖 +消耗（单节点约 `1.25~1.4 吨/秒`，含节能修正）。

## 6. 焚烧逻辑

- 地球储量每秒：`− 环等级焚烧（level_burn 表，2^l 指数） × 消耗乘区 − 研究点计费 − 建设计费 − 舰队维护`。
- 节点增加 → 环等级跳升 → 焚烧跳升；分配研究点/建设点/扩船进一步加压（都争夺同一 H3 家底）。
- **储量耗尽 = 断环**：焚烧/研究/建设/维护全部停扣，堆心开始降温（模块 04）；补入燃料即恢复。

## 7. 与其他模块的交互
- → 模块 01：环等级焚烧 + 研究/建设/维护支出 决定储量消耗。
- → 模块 04：断环时堆心降温，温度归零 = 终结；有燃料时堆心升温。
- → 模块 05：原 3 按钮已并入本多线系统（见模块 05）。
- → 模块 08：第二幕需求暴涨 = Lv2 节点；第三幕火星模块完成终局。
- → 模块 09：覆盖 100% → 全球环网 → 胜利。

## 设计原则（贯穿所有模块）

1. **极简操作**：玩家只做"拖拽画线 + 研究点分配（聚能环每升 1 级得 1 点，+/− 分到研究线，点越多越快也越耗 H3）+ 聚能环建设点数分配（+/− 控制交点灌入速度）+ 造船排队"，复杂度藏在系统里。
2. **单核心压力**：地球 H3 储量耗尽 = 环断环 = 堆心降温，温度归零 = 种族终结，是唯一硬性失败线。
3. **多线并行 + 玩家定向**：聚能环多条第技研线随存续并行推进，玩家可花额外 H3 加速某条线；线抵节点时三选一发展方向（海克斯式）。需求随节点增长，但先点哪条线、往哪走由玩家定。
4. **治愈反馈**：每一次卸货补入储量、堆心温度回升，都是正向多巴胺奖励。

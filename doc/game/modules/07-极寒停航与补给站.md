# 模块 07 · 极寒停航与补给站

## 1. 概述
两段式风险事件：先有"太阳耀斑"导致通讯中断、在途飞船失联；若飞船沿途没有"无人补给站"保暖，将**永久冻毁**。迫使玩家不只扩军，还要布局基础设施。

## 2. 极寒停航事件（太阳耀斑）

- **触发**：随机间隔（`100~150 秒`，`events.config.json`），持续 `20 秒`。
- **效果**：
  - 所有**在途飞船**进入"失联"状态，暂停推进（停在半路）。
  - 通讯中断：玩家暂时无法新建/修改航线（或操作延迟）。
- **结束**：耀斑退去，存活飞船恢复航行。

## 3. 无人补给站（保命基础设施）

- **建造前提**：无需前置解锁——建造面板直接选类型放置（实装为「磁场护盾发生器」，`building.table.json`）。放置后可**单独升级等级**（设计意图，当前未实现：建筑无等级字段、无升级 API；等级化属性规则详见模块 11）。
- **位置**：落在某条航线的中途节点（如月球线中点、木卫二线中点）。
- **作用**：事件期间，处于**磁场护盾发生器**背日半圆罩内（距建筑 ≤ 半径且位于背日侧，保全名额 `shipCap`）的失联飞船**不被冻毁**，仅停滞；无护盾覆盖的飞船 → 被冻毁，但事件结束后可**花 H3 重建**（从空闲池补回，不永久消失），重建消耗燃料形成权衡。
- **成本与升级**：建站消耗见模块 11（特殊建筑系统）；现版本为一次性放置（`building.table.json` 表内固定半径/保全名额），**等级化升级为设计意图、当前未实现**。

## 4. 风险权衡

```
不建补给站 + 耀斑来袭  ──▶  在途船永久冻毁（运力永久下降，可能连锁断供）
建补给站（花钱）       ──▶  船保住，但前期更穷、扩军更慢
```

> 设计意图：打破"无脑堆船"策略，逼出"运力 vs 基建"的取舍。

## 5. 与其他模块的交互
- ← 模块 05：补给站（护盾）建造不再依赖科技前置，建造面板直接可建。
- ← 模块 02：失联影响在途运输，间接威胁地球储量。
- → 模块 04：若断供致储量归零，堆心持续降温，温度归零则终结。
- → 模块 06：窗口期与耀斑期可能叠加，制造高压时刻。

## 6. 待确认 / 开放问题
- **（已定）** 护盾保护范围实装为**以建筑为圆心的背日半圆罩**（面朝太阳侧不在罩内；距心 ≤ 半径且限额 `shipCap`），罩内航线受保护；冻毁船事件结束后可**花 H3 重建**（不永久消失）。
- 耀斑预警：默认无预警；基建线"事件预警"节点解锁后，提前 10 秒预告（见模块 03）。
- 护盾半径 / 保全名额 / 重建 H3 成本的具体数值待平衡（见模块 11；等级表为设计意图、当前未实现）。

# 模块 07 · 极寒停航与补给站

## 1. 概述
两段式风险事件：先有"太阳耀斑"导致通讯中断、在途飞船失联；若飞船沿途没有"无人补给站"保暖，将**永久冻毁**。迫使玩家不只扩军，还要布局基础设施。

## 2. 极寒停航事件（太阳耀斑）

- **触发**：随机间隔（建议每 `120~180 秒` 一次），持续 `15 秒`。
- **效果**：
  - 所有**在途飞船**进入"失联"状态，暂停推进（停在半路）。
  - 通讯中断：玩家暂时无法新建/修改航线（或操作延迟）。
- **结束**：耀斑退去，存活飞船恢复航行。

## 3. 无人补给站（保命基础设施）

- **建造前提**：基建线解锁"补给站解锁"节点（见模块 03 / 模块 05）。补给站作为"特殊建筑"，放置后可**单独升级等级**（属性随级提升，详见模块 11）。
- **位置**：落在某条航线的中途节点（如月球线中点、木卫二线中点）。
- **作用**：事件期间，处于补给站**磁场护盾气泡**内的失联飞船**不被冻毁**，仅停滞；无护盾覆盖的飞船 → 被冻毁，但事件结束后可**花 H3 重建**（从空闲池补回，不永久消失），重建消耗燃料形成权衡。
- **成本与升级**：建站及后续单独升级消耗，见模块 11（特殊建筑系统）。补给站等级越高，保护半径 / 可保护船数 / 恢复速度越强。

## 4. 风险权衡

```
不建补给站 + 耀斑来袭  ──▶  在途船永久冻毁（运力永久下降，可能连锁断供）
建补给站（花钱）       ──▶  船保住，但前期更穷、扩军更慢
```

> 设计意图：打破"无脑堆船"策略，逼出"运力 vs 基建"的取舍。

## 5. 与其他模块的交互
- ← 模块 05：补给站科技是建造前提。
- ← 模块 02：失联影响在途运输，间接威胁地球储量。
- → 模块 04：若断供致储量归零，延续度终结。
- → 模块 06：窗口期与耀斑期可能叠加，制造高压时刻。

## 6. 待确认 / 开放问题
- **（已定）** 补给站保护范围为**以建筑为中心的圆形磁场护盾气泡**（视觉：护盾挡太阳风），气泡内航线受保护；冻毁船事件结束后可**花 H3 重建**（不永久消失）。
- 耀斑预警：默认无预警；基建线"事件预警"节点解锁后，提前 10 秒预告（见模块 03）。
- 护盾气泡半径 / 可保护船数 / 重建 H3 成本的具体数值待平衡（见模块 11 等级表）。

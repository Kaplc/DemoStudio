# 模块 06 · 引力弹弓窗口

## 1. 概述
通往**木卫二**（高产但极远）的航线不是随时划算。周期性出现"引力窗口"，期间该线飞船**速度翻倍、油耗减半**，是规划发船时机的核心策略点。

## 2. 触发与节奏（建议初值）

- **周期**：每 `90 秒` 出现一次窗口，持续 `20 秒`。
- **范围**：仅作用于"终点/途经木卫二"的航线（月球线不受影响，保持平稳）。
- **预警**：窗口来临前 `10 秒` 顶部/星图高亮倒计时，提示玩家"准备发船"。

## 3. 窗口期效果

| 属性 | 常态 | 引力窗口期 |
|------|------|------------|
| 飞行速度 | ×1.0 | ×2.0 |
| 航程油耗 | ×3.0（木卫二基础） | ×1.5（减半） |
| 单船往返净补 | 480 | 约 `600 − 60 = 540`（更快更多趟） |

> 策略：非窗口期尽量少跑木卫二线（油耗贵），把发车集中在窗口期，最大化产能。

## 4. 与其他模块的交互
- → 模块 02：改变特定航线速度/油耗。
- → 模块 01：间接影响木卫二净补效率。
- → 模块 08：第二幕解锁木卫二后才启用本机制。

## 5. 待确认 / 开放问题
- **（已定默认）** 窗口可被基建线"引力延长"卡延长（+5 秒），不可被缩短；窗口期仅影响航线速度/油耗，不加速其他风险；未来多行星各自独立窗口周期（扩展时再加）。
- 具体周期/时长数值待平衡。

# 模块 08 · 三幕进程系统

## 1. 概述
游戏分三幕推进，由"系统事件 + 目标达成"驱动，玩家专注调度而非宏观决策。

## 2. 三幕定义

| 幕 | 名称 | 进入条件 | 核心目标 | 新机制解锁 |
|----|------|----------|----------|------------|
| 第一幕 | 求生 | 开局 | 在家底烧光前建立月球短线，储量回血 | 基础航线；地球自有储量缓冲 |
| 第二幕 | 复苏 | 覆盖 4 交点（聚能环等级跳升，需求暴涨） | 解锁木卫二填补消耗缺口 | 航程油耗、引力弹弓窗口（模块 06）、极寒停航（模块 07） |
| 第三幕 | 质变 | 持续存续达标（已无积分货币） | 运回火星"环扩展模块"组建全球环网 | 全球环网任务线 |

## 3. 数值难度曲线（草稿，待平衡）

> 以下为**首版平衡草案**，需实测调参。核心张力：消耗量随幕次跳升，产能须同步跟上。

| 指标 | 第一幕 | 第二幕 | 第三幕 |
|------|--------|--------|--------|
| 聚能环焚烧率（吨/秒） | 2（Lv1，`level_burn` 表 2^l） | 4 交点 ≈ Lv7（128） | 8 交点 ≈ Lv16（65536） |
| 主力产线 | 月球（净补 160/趟） | 木卫二（净补 480/趟） | 木卫二 + 火星重货 |
| 地球储量初始/安全线 | 800 / >200 | 需维持正净流 | 需支撑环扩展模块长航 |
| 关键压力 | 开局倒计时 | 油耗×距离 | 超重货 + 事件叠加 |

## 4. 进度与解锁流程

```
开局(第一幕)
  └─ 建立月球线，储量回正 ──▶ 覆盖 4 交点 ──▶ 第二幕（焚烧随等级跳升）
        └─（第二幕）消耗率跳升，逼解锁木卫二
              └─ 木卫二线 + 引力窗口 + 极寒停航事件启用
                    └─ 存续满 240s 且覆盖 ≥8 交点 ──▶（第三幕）火星环扩展模块任务
                          └─ 运回组网 ──▶ 全球环网建成 ──▶ 胜利
```

- **（已定默认）** 三幕切换**不允许回退**（一旦进入更高幕不降级）；各幕时长不设硬目标，由进化/存续进度驱动。
- 第三幕"环扩展模块"重量与航程、各幕消耗率具体数值待平衡（见模块 01/03 数值草案）。

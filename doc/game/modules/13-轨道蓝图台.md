# 13 · 轨道蓝图台（航线编辑合并建造 + 真实转移轨道 + KSP 式轨道编辑）

> 实装现状文档（2026-09-29 落地口径）。用户需求原话：点「航线编辑」合并到建造模式和航线模式，
> 进入全息状态俯视角 + 全息网格地图；允许玩家放置建筑在任意轨道上（有轨道示意）；
> 航线编辑按真实的火箭转移轨道连接放置的建筑；要有编辑轨道的功能，类似 KSP 那种编辑轨道的蓝图。

## 一句话

底部「航线编辑」按钮进入统一**轨道蓝图台**：相机切近垂直俯视（88°，取景中心 = 冻结地球）+
全息网格 + 轨道环示意（**纯地月系**：2026-09-29 二次决策，太阳移除、地球冻结不公转，
其他星球同日起移除）；同一模式内拖天体/建筑建**转移轨道弧**航线、建造面板选型后
**点轨道环放置建筑**、点轨道设施/入轨建筑进入 **KSP 式轨道蓝图编辑**（半径/相位两个手柄
拖拽实时预览，松开应用）。

## 玩家流程

```
底部「航线编辑」（Btn_routeedit）
  └─ 进入蓝图台：俯视取景（dist=4600 pitch=88°，中心 = 冻结地球）+ 全息网格常驻 + 月球轨道环增亮
      + 地月本体全息质感（半透明青调；太阳/其他星球已移除）
      ├─ 建航线：拖星球/中转站 → 目标（原 UX 不变；线渲染为绕公共主天体的转移轨道弧）
      ├─ 放建筑：建造面板（Btn_build）选型「放置」→ 指针靠近轨道环自动吸附（ghost 绿/红）
      │           点按落位（锚 = 环属主：行星绕日环锚『太阳』，卫星环锚『母星』）
      ├─ 轨道编辑：点轨道设施（船坞/空间站）或入轨地图建筑选中
      │           ◇ 半径手柄（拖离/靠近环心 = 升降轨）· ▫ 相位手柄（沿环转动）
      │           松开应用（保持当下视觉角连续）· 再点建筑/Esc 取消
      └─ Esc / 再点按钮退出：回地球系默认取景，资产保留
```

## 关键口径

- **模式权威**：`GameMode.routeEditMode`（沿用旧字段，语义升级为蓝图台开关）；
  状态机在 `OrbitBlueprintComponent`（`orbitSel` / `edit` / `dragging` / `ghost`）。
- **显示口径（2026-09-29 用户决策：其他星球移除；二次决策：太阳移除 + 地球冻结不公转）**：
  蓝图台 = 纯地月系工作台（`OrbitBlueprintComponent.BLUEPRINT_BODIES` = earth/moon，不做
  幕解锁门控）——渲染（太阳组：本体/光晕/标签/全部绕日环，及其他行星/木卫二/任务线/
  引力窗口环全部隐藏）、吸附（只剩月球绕地环）、命中（`bodyAt`/`nodeAt` 只命中地月系，
  `sunAt` 收口；蓝图台双击天体不切观察视角）三处同源此常量。
- **全息质感（2026-09-29 用户反馈）**：蓝图台地月本体半透明（opacity 0.5）+ 青蓝自发光
  （`syncBlueprint` 材质接管，render 序晚于 `syncNodes` 故权威；退出还原不透明）。地球
  大气壳照常叠加，观感即"全息星球"。
- **全息网格**：`ensureGridCoverage` 按相机视野铺设网格线——蓝图台**空手态也铺设**
  （2026-09-29 修复：此前只在建造工具激活时铺设，`buildGroup` 组可见但无线条）。
- **地球冻结**：`helpers.starPosAt('earth')` 恒返回布局位（= 初相位位置，t=0 连续）。
  地月相对几何（月球环带 1200 / 航线距离 / 补给经济）本就以地球为基准，冻结不影响任何
  相对量；旧档读入地球瞬移到布局位（无需迁移）。月球仍绕冻结地球公转（恒星月周期不变）。
- **轨道环目录**：月球绕地环（锚 = 地球，半径 = `moons.moon.radius` = 1200）；
  吸附半径 48px（`ORBIT_SNAP_PX`）。绕日环（含地球环）已随太阳移除整体退场，
  锚 `'sun'` 不再由蓝图台产出（仿真 `tryPlaceOnOrbit('…','sun',…)` 能力保留，旧档兼容）。
- **轨道放置**：`buildings.tryPlaceOnOrbit(typeId, anchor, r, a)` —— 显式锚 + 半径钳制
  （天体显示半径 + pad，太阳锚用日距净空）+ 复用地面 `placementIssue`（耀斑/预算/日距/
  建筑间距）；`SimBuilding.anchor` 类型放宽到 `PlanetBodyId | 'sun'`（save v14 追记四，纯增量）。
- **转移轨道弧**：`helpers.transferArcControl/transferArcPoint` —— 二次贝塞尔，控制点 =
  弦中点沿「中点 − 公共主天体」方向外推 `弦长 × TRANSFER_ARC_BEND(0.24)`（弧凹向主天体 =
  以主天体为焦点的转移椭圆观感）。主天体判定：卫星端点 → 母星；建筑端点 → 锚天体；其余太阳。
  渲染 ribbon（24 段条带，UV 编码弧长供虚线）与飞船渲染位（`shipRenderPos`）同口径；
  **仿真计时/油耗仍按直线距离口径，弧是纯视觉**。
- **轨道编辑**：地图建筑 `buildings.setOrbit(id, r, a)`；轨道设施 `orbitBuild.setOrbitRing(id, ringR, a)`
  （`OrbitBuilding.ringR` 可选字段，缺省 `B.orbitBuild.ringRadius` 统一环）。
  相位连续口径：`a0 = a − ω·time`（纯时间函数，快照/读档天然确定）。
- **点按 vs 拖线仲裁**：链路建筑（中转站）按住拖 = 建航线（既有 UX/spec 锁定）；
  原点点按 = 切轨道编辑选中（`noteDragClick`，替代"站→自己"非法线报错）。
- **俯视取景**：`view.enterBlueprintView()` —— 2026-09-14「锁定地球视角」后唯一合法的
  太阳系全景入口（旧全景按钮/点太阳路径仍屏蔽）；滚轮落点平移在蓝图态放行
  （`scrollPan.allowed` 加 `|| routeEditMode`）；退出 `exitBlueprintView()` 回地球系。
  取景中心 = 冻结地球（`observeFocus(toWX(earth.x), toWZ(earth.y), 4600, 88°)`）。

## 设计取舍记录

- **其他星球移除（2026-09-29 用户决策）**："其他星球可以直接移除了不需要显示……保留地球
  和月球，什么游戏剧情都不要了，这些第几幕的已经重新制作了"——蓝图台视觉与交互收敛到
  地月系核心循环；**不做幕解锁门控**（火星/木卫二不随幕进度回归，等剧情/幕系统重做后再
  整体重排）。
- **太阳移除 + 地球冻结（2026-09-29 二次决策）**："移除太阳，地球不需要公转"——蓝图台
  成为纯地月系工作台：`starPosAt('earth')` 冻结在布局位，绕日环整体退场，取景中心改地球。
  冻结是仿真级（纯函数口径）：地月相对几何与运输经济零变化，月球照常绕冻结地球公转；
  太阳锚放置能力保留在仿真层（旧档兼容），仅蓝图台不再产出。想恢复太阳系全景，
  回滚 `BLUEPRINT_BODIES` / `starPosAt` 冻结分支 / `enterBlueprintView` 取景三处即可。
- **合并而非新增按钮**：用户定案「点击航线编辑合并到建造模式和航线模式」——`routeEditMode`
  字段保留（vm/HUD/e2e 调用面不变），语义升级；建造面板在蓝图态内变成轨道放置工具，
  不再与航线编辑互斥（旧 `enterBuildMode` 强制关蓝图的行为移除）。
- **轨道锚放宽到太阳**：行星绕日轨道环是俯视图里最主要的"轨道示意"，建筑上绕日轨道
  （与行星同环带公转）是 KSP 叙事的核心卖点；`buildingPos` 走 `starPosAt` 天然支持太阳锚，
  类型放宽 + 落位口径收口 `tryPlaceOnOrbit` 即可，仿真消费方零改动。
- **弧是视觉、直线是仿真**：真实 Hohmann 转移依赖相位角且改变航时/油耗模型，本轮把
  "真实转移轨道"落在**渲染与交互观感**（弧线 + 船沿弧），运输经济学口径不动——
  玩家读到的距离/油耗/航时与改版前一致，纯增量不破坏平衡。
- **KSP 手柄极简化**：2D 俯视下的 maneuver node 等价物 = 半径（∝ prograde/retrograde）
  + 相位两个手柄；不做偏心率/倾角（轨道保持圆轨模型，`orbitR`/`a0` 双参数即可完整表达）。
- **俯视 88° 而非 90°**：垂直俯视与 `up=(0,1,0)` 平行使 lookAt 退化（数值 NaN），
  88° 保持轨道环读成圆的同时规避退化（2026-09-14 移除 focusOn 的原因之一）。

# 模块 05 · 科技升级系统（已并入模块 03）

## 1. 概述
原设计的"底部 3 个常驻升级按钮（引擎 / 货舱 / 补给站）"已**合并进模块 03 的多线研究系统**：它们现在是 3 条研究线（引擎线 / 货舱线 / 基建线中的补给站节点），不再是独立按钮。科技成长统一为"**多线并行 + 加速 + 海克斯节点三选一**"。

## 2. 与原 3 按钮的对应关系

| 原按钮 | 现归属 |
|--------|--------|
| 引擎 | 引擎线（产能系） |
| 货舱 | 货舱线（产能系） |
| 补给站 | 基建线中的"补给站解锁"节点 |

## 3. 升级成本（统一为 H3 + 进度）

- **加速研究（研究点数制，2026-09-08 定稿）**：聚能环每升 1 级获得 1 点研究点（含开局起始等级），科研面板对五线以 +/− 按钮分配；每点对所在线推进速率加算提速（`1 + 点数 × researchPointRateAdd`），同时按点持续消耗 H3（每点 `researchPointCostPerS` 吨/秒）；断环或储量耗尽时点数加成与计费一并失效。原"按线开关超频"方案已废弃。
- **节点解锁**：海克斯三选一，是进度奖励，不额外花钱。
- 旧方案"文明积分"已不再单独需要；成本统一走 H3（加速）与进度（解锁）。

## 4. 与其他模块的交互

- → 模块 07：基建线解锁补给站是抗极寒停航的前提。

# 模块 04 · 堆心温度（原「人类种族延续度」）

> **2026-09-30 失败线下线（用户拍板）**：堆心温度降级为**纯展示指标**——归零不再判负、
> 不再触发失败结算，游戏当前无失败线（仅胜利结算，见模块 09）。降温/回温模型与
> 断环燃料门（停烧停建）保留；「重试本幕」机制随败局一并移除。
>
> **2026-09-08 改版（用户拍板）**：原「延续度 + 缓冲衰减倒计时」模型已下线。
> 聚能环的核心生存指标是**堆心温度**：无燃料时堆心**持续降温**；补入燃料后堆心**缓慢回温**
> （不会瞬间回满）。旧 `continuity` / `bufferLeft` / `bufferTotal` 字段与 `bufferAdd` /
> `recoverMult` 卡效果一并删除（存档 v7 兼容折算）。

## 1. 概述
顶部主指标，代表聚能环堆心的热状态。它**不是种族存续的抽象值，而是堆心的真实温度**：
有燃料则堆心升温运转，燃料耗尽则堆心持续降温（2026-09-30 起归零仅表示停摆深度，不再终结对局）。

## 2. 核心规则

- **有燃料（储量 > 0）**：环运转（`ring = 'running'`），焚烧/研究/建设照常；堆心温度向 100% 回升。
- **燃料耗尽（储量 ≤ 0）**：环断环（`ring = 'decaying'`），停烧停建；堆心温度**持续下降**
  （`100 / coreCoolSeconds` %/秒，默认 30 秒从满温降到 0）。
- **补入燃料**：环立刻恢复运转（`ring = 'running'`），堆心从当前温度**缓慢回温**
  （`100 / coreWarmSeconds` %/秒，默认 10 秒回满），不会瞬间回到满温。
- **归零（2026-09-30 起）**：温度停在 0% 仅作展示（断供深度可视化），**不触发任何结局**；
  补货后照常回温。
- **补货反馈**：飞船卸货补入地球储量 → 断环解除、堆心开始升温，以「回温」演出强化正向反馈。

## 3. 数值表示

- 显示范围：`0% ~ 100%`（堆心温度进度条）。
- 状态行：`升温中 · Ns 后满温` / `降温中 · Ns 后归零` / `满温运转`。
- 配色：升温中暖色（#ffe9a8 / 进度条 #ffb03d），降温中冷红告警（#ff5a4a）。
- 预警：当「地球储量」低于危险阈值（`< dangerReserveSeconds` 秒余量）时，储量与温度转冷色告警。

## 4. 与储量的关系（关键澄清）

```
地球 H3 储量 > 0  ──▶  环运转（running）  ──▶  堆心升温（→100%）
地球 H3 储量 = 0  ──▶  环断环（decaying）  ──▶  堆心降温（→0% = 停摆展示，不判负）
```

- 堆心温度**不独立变化**，只随「储量是否 > 0」切换升温/降温方向。
- 玩家真正的"操作对象"是地球储量（模块 01），堆心温度是它健康的可视化。

## 5. 与旧「缓冲衰减」的差异

| 维度 | 旧模型（延续度 + 缓冲） | 新模型（堆心温度） |
|------|------------------------|-------------------|
| 无燃料表现 | 一次性缓冲倒计时（`bufferLeft` 秒） | 温度进度条持续下降（无固定倒计时 UI） |
| 补燃料表现 | 延续度按固定速率回升 | 堆心从当前温度缓慢回温（0→100 需 10s） |
| 归零后果 | 延续度 ≤ 0 = 失败 | 展示停摆深度（2026-09-30 起不判负） |
| 卡效果 | 储备扩容（+缓冲秒）/ 恒温冗余（+回升倍率） | 已随缓冲模型删除 |

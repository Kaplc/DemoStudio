# 模块 04 · 人类种族延续度

## 1. 概述
顶部主指标，代表人类文明是否还在存续。它**不是温度**，而是"种族是否延续"的抽象度量。其生存在于聚能环运转。

## 2. 核心规则

- **环运转时**：延续度维持在「当前等级上限」（默认 100%），稳定不降。
- **环缓冲熄灭时**：储量耗尽后并非瞬间归零，而是进入**缓冲衰减期**——延续度从满值随时间逐步下降（环「慢慢熄灭」）；此期间若在途船补入燃料、储量回正，则延续度回升、环恢复。缓冲耗尽、延续度归零 → 触发模块 09 失败（种族终结）。
- **补货反馈**：飞船卸货补入地球储量 → 延续度以短暂"脉冲/回升"动画强化正向反馈（即便数值已满，也给演出奖励）。
- **分段演出（已定）**：延续度按区间呈现不同观感——`100% 繁荣`（暖绿，环稳健）、`~60% 挣扎`（橙黄，缓冲期告警）、`0% 终结`（冷红，文明湮灭）。不同区间配色与提示语不同，强化情绪。

> 设计选择：延续度是聚能环运转的**下游结果**；本身不独立衰减，但储量耗尽后进入**方案 B 缓冲衰减**（已采用）：延续度随缓冲期从满值缓降，给玩家最后一波补救机会，更有戏剧性。

## 3. 数值表示

- 显示范围：`0% ~ 上限%`（上限由模块 03 聚能环等级决定）。
- 当前默认：满值即 100%，环不停则常驻 100%。
- 预警：当「地球储量」低于危险阈值（如 `< 60 秒余量`）时，顶部指标转为冷色告警闪烁，提示玩家"快没燃料了"。

## 4. 与储量的关系（关键澄清）

```
地球 H3 储量 > 0 （且有补入预期）  ──▶  聚能环运转  ──▶  延续度 = 上限（存续）
地球 H3 储量 = 0 且无在途货物      ──▶  聚能环进入缓冲衰减（慢慢熄灭）  ──▶  延续度随缓冲期缓降 → 归零 = 终结
```

- 延续度**不独立衰减**，只随环的开关切换。
- 玩家真正的"操作对象"是地球储量（模块 01），延续度是它健康的可视化。

## 5. 与其他模块的交互
- ← 模块 03：环等级决定上限；存续进度累积触发环进化。
- ← 模块 01：储量充足 = 环运转 = 延续。
- → 模块 07：极寒停航不直接灭延续度，但飞船失联会断了补货，间接逼停环。

# 模块 01 · 资源与燃料系统

## 1. 概述
游戏只暴露**两种核心数值**，降低认知负担：
- **燃料（氦-3）**：维持聚能环运转的唯一货币。
- **运力**：飞船数量 × 单船货舱容量，决定单次能拉回多少燃料。

此外有一个**隐含库存**——`地球 H3 储量`（家底），是聚能环直接焚烧的对象。

## 2. 氦-3 的三种存在形态

| 形态 | 位置 | 说明 |
|------|------|------|
| 地球家底储量 | 地球（聚能环燃料仓） | 开局一笔固定值，环实时焚烧；飞船卸货补入此处 |
| 在途货物 | 飞船货舱 | 已从星球装船、尚未卸回地球的燃料 |
| 星际矿藏 | 各资源星 | 月球（低产近）、木卫二（高产远）、火星（特殊重货） |

## 3. 地球 H3 储量（核心缓冲）

- **初始值**：`800`（单位：吨 H3；配置 `earthH3Start`，`balance.ts` 默认同值，待平衡）。
- **实时变化**：
  - 每秒 `-基础消耗率 × 聚能环等级系数`（见模块 03）。
  - 飞船卸货时 `+货舱容量`（扣除本次航程油耗后净值）。
  - 反向航线（模块 02）装建材时，按 `建材折算系数 × 载重` 从本储量**同步扣除 H3**（建材不单独立账，直接与燃料争夺）。
- **上限**：**不设上限**，储量可无限累加；压力来自焚烧速率而非囤积上限。
- **失败联动（堆心温度式，2026-09-08 改版）**：储量 `≤ 0` 后并非立即结束，而是**聚能环断环**——堆心开始**持续降温**（`coreCoolSeconds` 秒从满温降到 0）；此期间只要在途船补入燃料，环即恢复运转、堆心**缓慢回温**（`coreWarmSeconds` 秒回满）。直到堆心温度归零，才触发模块 09 失败。旧「一次性缓冲倒计时」已下线（见模块 04）。

> 设计意图：开局即"倒计时"。玩家必须赶在家底烧光前接上第一条月球短线。烧光后堆心降温（约 30 秒窗口），仍需尽快补货。

## 4. 星际产量（建议初值）

| 星球 | 单船满载量 | 距离（影响航程油耗） | 解锁幕 |
|------|-----------|----------------------|--------|
| 月球 | 200 | 近（油耗 ×1.0） | 第一幕 |
| 木卫二 | 600 | 远（油耗 ×3.0） | 第二幕 |
| 火星 | 极远高产 H3（产量极高但距离极远、油耗巨大） | 极远（油耗 ×6.0 估） | 第三幕 |

## 5. 与其他模块的交互
- → 模块 02：运力决定单船货舱；航程油耗从这里扣。
- → 模块 03：聚能环等级决定焚烧速率。
- → 模块 05：科技升级（货舱/引擎/船队）**消耗 H3 支付**，改变运力与油耗（与生存争夺燃料）。
- → 模块 02.5.1：玩家可**主动花 H3 建造新船**（与焚烧/研究点计费争夺同一家底）。
- → 模块 04：储量充足是堆心温度升温存续的前提。

## 6. 待确认 / 开放问题
- **（已定）** 储量不设上限；科技升级用 H3 支付（不新增货币）；环停为「堆心降温、慢慢熄灭」而非瞬间失败（在途补燃料即回温恢复）；火星为极远高产 H3；反向建材从 H3 折算。
- 建材折算系数（装货扣多少 H3）的具体数值，待模块 11 回填。
- 堆心降温/升温时长（`coreCoolSeconds` / `coreWarmSeconds`）的具体曲线，待模块 04 定稿。

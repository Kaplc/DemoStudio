# 模块 02 · 航线与飞船系统

## 1. 概述
这是游戏**唯一的核心操作**：在星图上拖拽画线建立自动循环航线，飞船据此往返运输。
支持两种航线方向：
- **正向（星 → 地）**：运回氦-3 燃料补入地球储量（核心生存循环）。
- **反向（地 → 星）**：把建材/补给从地球运往外星，用于建造补给站等设施（挂模块 11「建材方案」）。

## 2. 建立航线（拖拽画线 · 交互 spec）

手感优先级最高，拆成"输入 → 命中 → 反馈 → 生效 → 引导"五步可落地规格。

### 2.1 输入手势（双端统一）
- **鼠标**：节点上 `mousedown` → `mousemove` 拉线 → `mouseup` 落目标节点。
- **触屏**：`touchstart` → `touchmove` → `touchend`；画布层 `touch-action: none`，禁页面滚动手势干扰。
- **方向识别**：从资源星拖向地球 = 正向；从地球拖向资源星 = 反向；均识别，松开后按起止节点自动判定方向。

### 2.2 命中与吸附判定
- 每个节点有**命中半径**（建议 `节点半径 + 24px` 容差），终点落入即命中并**吸附**到节点中心 + 高亮。
- **合法性**：起止为「星—地」任意一端组合均合法（正/反向）；两端同类型（星→星 / 地→地）非法。

### 2.3 视觉状态机
| 状态 | 触发 | 视觉表现 |
|------|------|----------|
| idle | 未操作 | 节点静止，光标 grab |
| dragging-空 | 终点在空白 | 半透明灰虚线跟手 |
| dragging-命中星 | 终点入星命中圈 | 线变蓝、星脉冲 |
| dragging-命中地 | 终点入地球命中圈 | 线变**绿**、地球脉冲、浮层"可建立" |
| invalid | 两端同类型/越界 | 线变红 + 轻微抖动 |
| established | 合法松开 | 线固化，出现流动光点（**1 光点 = 1 艘真船**） |

> **光点语义（已定）**：光点数量严格等于派到该航线的飞船数。同线多船时光点沿航线**均布流动**，流速反映当前航速（受模块 05「引擎/航速」海克斯卡 / 模块 06 引力窗口影响）。运力分配一眼可见。

### 2.4 即时反馈（降低试错成本）
- 终点命中合法节点时，线旁**实时浮层**显示该航线预计：`单船货舱 / 往返油耗 / 净补（正向）或 载建材量（反向）/ 航程`，随已解锁科技实时变化（数据来自模块 01/04）。
- 音效：拉线 `whoosh`；合法 `ding`；非法 `buzz`。
- 松手不合法：线**弹回**起点（弹性动画 ~150ms），不建立、无惩罚。

### 2.5 生效与边界
- 合法松开 → 航线成立，默认派 **1 艘**空闲飞船（增船见 2.7）。
- **平行多条**：同两节点间可建多条平行航线（多船跑同线），不合并；视觉错开 2~4px 防重叠。**每条平行航线独立计算油耗与运力（N 条 = N 船 = N 份油耗）**。
- **交叉**：允许任意交叉，渲染分层（z-order），逻辑互不干扰。
- **删除**：点击航线 → 弹出确认条（非模态、~1.5s 内可撤销）→ 删除后在途船就近返航卸货（不丢货）。
- **空白/非节点松手**：线消失，不建立。

### 2.6 首次画线强制引导（已定）
- **触发**：仅首局、且玩家尚无任何航线时启用。
- **锁定**：引导期间禁用其他 UI 操作（科技卡、暂停等），聚焦画线。
- **引导演出**：资源星与地球节点脉冲高亮，二者间播放循环**箭头动画** + 提示语「按住资源星，拖一条线到地球」。
- **完成条件**：玩家成功建立第一条合法航线后，引导自动解除，其余 UI 解锁。
- 引导期间任何非法拖拽被忽略并轻提示「再试一次，从星拖到地球」。

### 2.7 派船方式（两种都要 · 已定）
1. **航线面板 +/−**：点选航线弹出**小型浮层**，用 `+` 从空闲池派船、`−` 召回（浮层显示：船数、净补/航程实时、删除按钮）；点击空白或别处自动关闭。
2. **拖平行航线（老手捷径）**：在同两节点间再画一条线 = 再派 1 艘，等价于 `+`；删一条平行航线 = 召回 1 艘。
- 两种方式共享同一「空闲飞船池」，面板与平行航线数始终对账一致。

## 3. 飞船循环运输

- **正向单船**：资源星装 H3 满仓 → 飞行 → 地球卸货（补储量）→ 空返装货，无限循环。
- **反向单船（循环持续供料）**：地球装建材满仓 → 飞行 → 外星卸货（建站/供料）→ 空船返回 → 再装，无限循环供料。
- **船只分配**：总运力 = 飞船总数；每条航线可派 1~N 艘，派船方式见 2.7。
- **飞行速度**：基础值受模块 05「引擎/航速」海克斯卡与模块 06「引力窗口」影响。

## 4. 航程油耗（关键压力）

- 每次飞行消耗 H3 = `距离系数 × 单船基础油耗`。
  - 例：月球线 `1.0 × 20 = 20`；木卫二线 `3.0 × 20 = 60`。
- **正向净卸货量** = `货舱容量 − 往返油耗`：月球 `200 − 40 = 160`；木卫二 `600 − 120 = 480`（高产抵消高耗）。
- **反向航线油耗**：航行与所装**建材均从地球 H3 家底折算扣除**（装货时按 `建材折算系数 × 载重` 扣 H3，不单独立账）；净收益体现为外星设施建设进度（模块 11）。建材直接加剧燃料争夺，是核心权衡之一。
- 含义：飞得越远单次拉得越多（或建得越多），但油耗也高，逼玩家升级引擎（降系数）或等引力窗口（省油）。

## 5. 运力构成

| 项 | 公式 | 受谁影响 |
|----|------|----------|
| 飞船总数 | 初始 3，可主动 H3 造船（5.1），「扩编船队」卡额外 +1 | 主动建造 + 海克斯升级型 |
| 单船货舱 | 初始 200 | 模块 05「扩容货舱」卡 |
| 总运力 | 飞船数 × 货舱 | 以上两者 |
| 空闲池 | 总数 − 各航线已派 | 派船/召回实时变动（2.7） |

### 5.1 飞船建造（主动扩军 · 已定）
- 玩家可随时在地球船坞**主动花 H3 建造新船**：消耗 `建船 H3 × 数量` + 建造耗时 `T 秒`（具体数值待平衡）。
- 与「扩编船队」海克斯卡（+1）叠加：**飞船总数 = 初始 3 + 主动建造数 + 扩编卡数**。
- 张力：造船消耗 H3（与燃料焚烧、超频研究争夺同一家底），且新船需从空闲池派出才产生收益；极寒失联的船也可用同机制重建（H3 足够时）。

## 6. 与其他模块的交互
- → 模块 01：卸货净补地球储量；油耗从这里出。
- → 模块 05：引擎/航速、扩容货舱、扩编船队相关海克斯卡。
- → 模块 06：引力窗口期内油耗/速度变化。
- → 模块 07：极寒停航时，在途飞船失联（依赖补给站保命）。
- → 模块 11：反向航线运输的建材/补给，用于外星设施建设。

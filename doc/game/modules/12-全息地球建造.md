# 12 · 全息地球建造（环节点落位 / 地表建筑 / 轨道建筑）

> 实装现状文档（2026-09-18 底部分类改版后口径）。全息地球建造 2026-09-12 立项（环节点空间落位 + 冰雪融化 + 地表建筑），2026-09-15 起与矿点勘探同口径原地包络取景，2026-09-18 底栏改版为「资源 / 地表建筑 / 轨道建筑」三分类 + ⚡ 环节点独立按钮。

## 一句话

点星球信息面板「全息地球」进入全息视角：左侧入口面板隐藏，底部工具条 4 按钮切换右侧全息面板内容——**资源**（矿点 + 矿建）、**地表建筑**（融化圈内放置）、**轨道建筑**（orbit_build 表嵌入直建）、**⚡ 环节点**（待落位节点球面落位，融冰开圈）。

## 玩家流程

```
星图点地球 → 信息面板 → 「🌐 全息地球」
  ├─ 相机：原地包络取景（35° 斜视角环绕 · 边缘平移关 · 左键空闲环绕）
  ├─ 左侧入口面板隐藏（退出全息自动恢复，2026-09-18 定案）
  └─ 底部工具条（仅地球态显示）
      ⚡ 环节点 ── 切落位工具 + 面板环节点视图（再点取消工具）
      资源     ── 矿点行（金属矿脉 e1）+ 矿建建造区 + 矿点详情
      地表建筑 ── building 表工具行（「选用」→ 点球面落位，须在融化圈内）
      轨道建筑 ── orbit_build 表行（船坞/空间站，「建造」直接投放轨道施工）
          ✕ 退出 ── closeHologram（保持当前相机位置，不重新取景）
```

- **环节点**：只有「已交付槽位」（聚能环建设泵交付，见模块 03）才可落位；落位后周边 `meltRadiusDeg`（默认 26°）角半径内冰雪消融，成为地表建筑可放置区。连续落位不退工具。
- **地表建筑**：一次一放（落成即退出工具）；校验链 = 耀斑中断 / 预算 / 融化圈 / 球面角距（`surfacePlacementIssue` 单一口径）。
- **轨道建筑**：2026-09-18 起嵌入全息面板（原「近地轨道建设」面板仍从星图入口可用，数据同源）；船坞建成后点轨道船坞开造船面板。
- **矿点勘探态**（月球/水星等）：底部分类工具条整组隐藏，面板维持矿点 + 矿建全显（2026-09-12 行星矿产口径不变）。

## 底部分类状态机（2026-09-18 改版核心）

权威状态在 GameMode，脚本只做差分呈现：

| 状态 | 字段 | 变更入口 |
|---|---|---|
| 面板内容分类 | `holoTab: 'ring'\|'resources'\|'surface'\|'orbit'` | `setHoloTab()`（底部 3 分类按钮）；`openHologram` 重置 `'resources'` |
| 放置工具 | `holoPlaceTool: {kind:'ring'} \| {kind:'building',typeId} \| null` | `setHoloTool()`（⚡ 环节点按钮 / 面板「选用」行） |

- ⚡ 环节点按钮 = `setHoloTool('ring')` + `setHoloTab('ring')`（切工具同时跳视图；再点按钮取消工具、视图停留）。
- 分类与工具正交：地表建筑分类里点「选用」只改工具不动分类。
- 分类选中态表达：按钮金色 `#ffe9a8` + 非 ring 分类加 `●` 前缀（口径在 `holoHudModel.holoTabButtonLabel`，单测锁定）。

## 设计取舍记录

- **业务入口下架**：原全息底栏转发主 HUD 的建造/运输/航线/科研/聚能环/火箭设计 6 按钮，2026-09-18 用户决策「改成只有 3 个按钮」后全部移除——全息态专心地球建造，业务面板退出全息后从主 HUD 进（主 HUD 按钮原样保留）。
- **轨道建筑嵌入**：用户选定「嵌入全息面板」而非跳出现有轨道面板——不脱离全息模式即可投放轨道施工；数据与轨道建设面板同源（`orbitBuildTypeRows` 单一投影，两处共用）。
- **环节点独立按钮**：用户选定「单独保留按钮」（共 4 个）而非并入地表建筑分类——节点落位是高频主循环操作，一键直达。
- **入口面板隐藏**：全息开启后左侧星球信息面板隐藏、退出恢复（`planetInfoSel` 不清，纯显隐差分），用户定案"打开全息模式左侧这个进入的入口面板要隐藏"。

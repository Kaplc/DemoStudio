# 验收用例：HOI4 类大战略游戏

> 对应方案：[plan.md](./plan.md)。用例按分期组织；标注 [GM] 的走 GM 控制台/调试桥，标注 [e2e] 的进 `tests/e2e/hoi4/`。

## P0 地图与时间

| # | 用例 | 期望 |
|---|---|---|
| P0-1 | 启动 hoi4 工程 | 加载地图场景，地形底图渲染，无报错 |
| P0-2 | 点选任意省 [e2e] | 高亮该省，省面板显示正确州/地形/VP 数据 |
| P0-3 | 切换政治/地形地图模式 | 政治模式下各省按所属国颜色重染，边界线清晰 |
| P0-4 | 点顶栏暂停/1~5 速 | 顶栏日期按档位推进/停止；暂停后所有面板数值冻结 |
| P0-5 | [vitest] GameTime：speed=5 推进 1 现实秒 | hour 精确 +16，含跨日 onDay 触发次数正确 |
| P0-6 | 相机滚轮/拖拽 | 缩放有 min/max 夹取，平移有边界，屏幕边缘平移可用 |

## P1 内政经济

| # | 用例 | 期望 |
|---|---|---|
| P1-1 | 建造队列排一座民厂 | 扣除库存/占用槽位，进度条按日推进，完工后省面板厂计数 +1 |
| P1-2 | 军厂挂步兵装备生产线 | 产出效率从低值逐日爬升到上限，装备库存按日增加 |
| P1-3 | 资源缺口 | 钢不足时对应生产线产出按配置降档，顶栏资源变红 |
| P1-4 | 切换经济法 | PP 扣减、民用工厂占比（consumer goods）按表生效 |
| P1-5 | [vitest] 月度经济结算 | 给定输入（厂数/法/资源），产出序列与手算一致 |
| P1-6 | [GM] `tick(720)` 快进一个月 | 与 5 速挂机同帧长的结果一致（确定性） |

## P2 军事

| # | 用例 | 期望 |
|---|---|---|
| P2-1 | 编制设计器保存模板并训练 | 人力/装备库存预扣，训练完成出师，部署到选中省 |
| P2-2 | 师下达跨 3 省移动令 | A* 路线合理，逐省行军，进度可见 |
| P2-3 | 师进入有敌师省份开战 | 战斗面板弹出，组织度条逐小时变化，宽度按方向上限投入 |
| P2-4 | 战斗至守方组织度归零 | 守方撤退，攻方占领该省，政治色更新 |
| P2-5 | 断补给惩罚 | 被切孤立的师攻防/组织恢复下降、逐日损耗 |
| P2-6 | [vitest] 战斗解算 | 固定输入下双方组织度曲线确定；地形/堑壕修正生效 |
| P2-7 | [GM] `war(a,b)` / `occupy(prov)` | 直接开战/占省，用于跳过前期搭场景 |

## P3 内容层

| # | 用例 | 期望 |
